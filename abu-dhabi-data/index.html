How to use the data

A market screen, not a valuation.

Area-level activity helps establish context. A property decision still needs suitable unit and building comparables, service charges, condition, floor, view, tenancy and legal checks.

Current, not instant

The source dashboard is loaded live, but newly registered transactions appear when ADREC publishes them.

Official classifications

District, community and project names follow the source system and may differ from marketing names.

Indicative analysis

Transaction and price indicators should be checked against property-specific evidence before making a decision.

Questions

About the Abu Dhabi data page

Is this Abu Dhabi transaction data live?

The page retrieves the current public DARI and ADREC dashboard whenever it loads. Data follows ADREC's publication cycle, so a newly registered transaction may not appear immediately.

What information can I filter?

The source dashboard provides filters for transaction and property types, dates, districts, communities, projects and layouts. Available filters can change when ADREC updates its dashboard.

Does James Ravi control or modify this data?

No. The dashboard is loaded directly from the official public source. This website adds context and navigation but does not change the underlying records.
